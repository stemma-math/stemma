Stemma 0.5.2 follows the repository to its new name, [stemma-math/stemma-signum](https://github.com/stemma-math/stemma-signum).

## What upgrading means for a library

Nothing to do beyond `stemma upgrade`, which points the library at the new address:

- `lakefile.toml` requires stemma's Lean package from `stemma-math/stemma-signum`, and the manifest follows it.
- The workflow in `.github/workflows/stemma.yml` downloads the command line from the new repository's releases.
- New libraries' `README.md` links to it.

The old address still redirects, so libraries that have not upgraded keep building.
