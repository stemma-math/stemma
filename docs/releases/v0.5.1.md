Stemma 0.5.1 makes the site look as stemma-math/design means it to, with stemma-math/design v0.3.0.

## What upgrading means for a library

Nothing to do beyond `stemma upgrade`. The site changes how it looks:

- Pages read as a document: the text, headings, lists and code take the design system's sizes, instead of the Verso manual's.
- Formulas are set in New Computer Modern Math at the size of the text.
- Blocks of Lean sit in a box, as code does in a document.
- The header, the table of contents, the search box and the buttons to the previous and next pages take the design system's look.

## New

- An appearance switch (system, light or dark) at the foot of the table of contents, kept from page to page.
