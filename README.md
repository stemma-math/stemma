# Stemma

Stemma is a standard, and a command line that implements it, for doing
mathematics in the age of AI agents.

## Development

The development environment is a Nix flake built with
[blueprint](https://github.com/numtide/blueprint); its files are in `nix/`.

```sh
nix develop   # enter the development shell
nix fmt .     # format the Nix code
```
